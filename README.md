## What I build

- Local desktop and Android apps, including Vault (public beta)
- Linux automation that removes repetitive work
- Compact desktop widgets with useful controls
- Utilities for files, website checks and messaging

## Featured projects

| Project | What it does | Stack |
| --- | --- | --- |
| [**Vault**](https://github.com/NODEPY/vault) | Local password manager for desktop and Android, with encrypted backups and a Chrome companion. Public beta; see its documented testing limits. | `Python` `PySide6` `Java` `JavaScript` |
| [**NØDE File Organizer**](https://github.com/NODEPY/node-file-organizer) | Watches Downloads and sorts files by category, with dry-run and undo modes | `Python` `Watchdog` `systemd` |
| [**NØDE Link Checker**](https://github.com/NODEPY/node-link-checker) | Checks internal website links, reports errors and exports JSON for automation | `Python` `Requests` `Beautiful Soup` |
| [**Eww SoundCloud Widget**](https://github.com/NODEPY/eww-soundcloud-widget) | Linux music widget with playback, seeking, cover art and system volume controls | `Eww` `SCSS` `MPRIS` |
| [**NØDE Telegram Sender**](https://github.com/NODEPY/node-telegram-sender) | Configurable Telegram message sender with FloodWait handling | `Python` `Telethon` |
