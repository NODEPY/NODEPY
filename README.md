## Now building

**[Nodi](https://github.com/NODEPY/nodi)** — encrypted file transfer between macOS and Android on your local network. No cloud, no accounts.

Pair over Wi-Fi with a matching code (QR still works as a fallback), send files in sequence, and keep TLS 1.3 plus SHA-256 checks on the path. Alpha 3 is out; folder transfer, resume, and desktop Linux/Windows apps are still ahead.

[Repository](https://github.com/NODEPY/nodi) · [Downloads](https://github.com/NODEPY/nodi/releases) · [Changelog](https://github.com/NODEPY/nodi/blob/main/CHANGELOG.md)
